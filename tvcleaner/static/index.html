Checking Wi-Fi hardware…

The TV stays on its own Wi-Fi. PiTV scans that network through the USB adapter. You can type a hidden network name even if scanning finds none. Guest isolation or a captive portal can block TVs or internet.

Set the name and password for the Pi’s built-in Wi-Fi access point. Phones and tablets connect here to open pitv.local.

1

Find your TV

Turn on debugging on the TV. PiTV checks ALL connected local networks it can see (up to four, with up to 256 addresses each) and USB. Approve this Pi on the TV screen.

One press starts the cleanup. PiTV saves how the TV was before, turns off the checked items, and checks the result. You can restore this cleanup if something does not work. Keep this page open until the result appears.

4

Check your TV

Test Home, remote buttons, inputs, streaming and network on the TV.

  • Home opens and the remote works.
  • HDMI or Live TV inputs work.
  • Streaming apps play, and the TV stays online.
  • Reboot the TV and check again.
Cleanup history and restore

Restore uses the saved state from a specific run on the same TV.

Update PiTV

PiTV checks the public release repo after boot and about hourly, then installs newer stable app and profile releases. This does not install TV firmware. Automatic TV cleanup stays off after an update.
